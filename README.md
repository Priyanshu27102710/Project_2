# CryptoM5 – Cryptocurrency Website

## 📌 Project Overview
CryptoM5 is a cryptocurrency website landing page created using HTML and CSS. The website features a modern design with a purple theme, cryptocurrency information, feature sections, and interactive buttons.

## 🚀 Features
- Responsive-style website layout
- Navigation bar with Home, Live Demo, Live Demo Blocks, and Buy Now options
- Hero section with cryptocurrency introduction
- Statistics section displaying wallets, clients, and traders
- Cryptocurrency feature cards
- Tips and tricks section
- Blog-style content with dates and Learn More buttons
- Hover effects on buttons and images
- Font Awesome integration

## 🛠️ Technologies Used
- HTML5
- CSS3
- Font Awesome

## ▶️ How to Run the Project
1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Make sure all images are available inside the `Image` folder.
4. Open `index.html` in your browser, or use the Live Server extension in VS Code.

## 🎯 Project Objective
The objective of this project is to practice HTML and CSS by creating a cryptocurrency landing page with an attractive layout, feature sections, navigation, and hover effects.
